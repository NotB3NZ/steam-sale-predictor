## Structural Integrity

### Is the CSV structurally valid?

**Partially.** There is one confirmed structural defect in the header row, but the data rows themselves are fully consistent.

### The DiscountDLC count Problem

**Finding:** The raw header contains **39 fields**, but all 125,855 data rows contain **40 fields**. This is a 1-field mismatch.

**Root cause:** Header column index 7 reads `DiscountDLC count` — a concatenation of what should be two separate columns: `Discount` and `DLC count`. A comma is missing between them in the header row.

**Evidence:**
1. Header field count: 39. Data row field count: 40 (100% of rows, zero exceptions).
2. When the header is corrected to split `DiscountDLC count` → `Discount` + `DLC count`, the data aligns perfectly:
   - Column 6 = Price (float values like 4.99, 0.0)
   - Column 7 = Discount (integer values 0–100)
   - Column 8 = DLC count (integer values ≥ 0)
3. All downstream columns (About the game, Supported languages, etc.) contain semantically correct values under the corrected 40-column header.

**Impact:** If loaded naively with `pd.read_csv()` using the raw header, pandas assigns 39 column names to 40 data fields, silently shifting everything after index 7 by one position. `About the game` text would appear under `DLC count`, etc.

**Resolution used in inspection script:** The script supplies a corrected 40-column `names=` list and skips the malformed header row. The original file is **not modified**.

### Are there any other structural problems?

No. Beyond the header issue:
- 100% of data rows have exactly 40 fields
- No rows were skipped or flagged by the CSV parser
- Quoting appears properly handled (descriptions contain commas, newlines, quotes)

## Potential Modeling Variables

### Safe to use (stable over time)
- **Release date** → derive `age_at_sale` (days between release and sale start)
- **Price** → base price (assuming this is the non-discounted price)
- **DLC count** → product complexity indicator
- **Genres, Tags, Categories** → content classification (need multi-value encoding)
- **Required age** → maturity rating proxy
- **Windows, Mac, Linux** → platform availability
- **Achievements** → generally set at release; minor leakage risk
- **Developers, Publishers** → high cardinality; may use grouping
- **Supported languages, Full audio languages** → localization effort proxy (count)

### Usable with caution (mild leakage risk)
- **Metacritic score** — typically assigned close to release, but can update
- **Estimated owners** — binned ranges; timing of estimate unknown

### High leakage risk (snapshot at unknown time)
- **Peak CCU** — lifetime peak, not pre-sale peak
- **Positive / Negative** — lifetime review counts
- **Recommendations** — lifetime total
- **User score** — timing unknown
- **Discount** — current discount at scrape time, not pre-sale state
- **Average/Median playtime** — lifetime or recent-window stats

### Not useful for modeling
- **AppID, Name** — identifiers only
- **About the game** — free text (could be used for NLP features later, out of scope)
- **Header image, Website, Support url/email, Screenshots, Movies** — URLs/metadata
- **Metacritic url** — URL only
- **Reviews, Notes, Score rank** — high missingness or unclear provenance

## Potential Leakage Risks

When predicting whether a game participates in **Steam Autumn Sale YYYY**, we can only use information known **before** the sale starts. The following columns represent snapshots taken at an **unknown** time (likely the dataset's scrape date, not the historical sale date):

| Column | Risk | Reason |
|--------|------|--------|
| Peak CCU | HIGH | All-time peak — includes post-sale activity |
| Positive / Negative | HIGH | Lifetime review counts accumulate indefinitely |
| Recommendations | HIGH | Lifetime total |
| Estimated owners | HIGH | Lifetime estimate |
| Avg/Median playtime forever | HIGH | Lifetime stats |
| Discount | HIGH | Reflects scrape-time discount, not pre-sale state |
| Avg/Median playtime two weeks | MEDIUM | Recent window, but scrape timing unknown |
| User score | MEDIUM | May reflect post-sale sentiment |
| Metacritic score | LOW | Usually established near release |

**These columns must NOT be used as raw features for historical sale prediction.** In Phase 2+, some may be reconstructable from ITAD or SteamSpy historical snapshots, but others must be dropped or treated as unavailable.
